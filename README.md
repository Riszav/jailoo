# Жайлоо

Онлайн-настольная игра для 2–8 игроков в браузере: юрты и аилы на горных пастбищах, тропы, торговля, карты развития и буран. Свободные места можно отдать ботам.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Откройте http://localhost:3000. Во время разработки удобнее `npm run dev`: сервер сам перезапускается, когда меняются `server.js` или `shared/logic.js`. Порт меняется переменной `PORT`:

```bash
PORT=8080 npm start
```

## Хранилище и деплой на Render

Без переменной `DATABASE_URL` партии, аккаунты и рейтинг лежат в файлах `data/*.json` — этого хватает для локального запуска. На Render файловая система стирается при каждом деплое и перезапуске, поэтому там нужна база Postgres:

1. Создайте базу: бесплатную в [Neon](https://neon.tech) или Supabase, либо Postgres в самом Render.
2. В настройках веб-сервиса Render → Environment добавьте `DATABASE_URL` — строку подключения (у Neon она уже с `?sslmode=require`; у Postgres из Render берите Internal Database URL).
3. Задеплойте. Таблица `kv` создастся сама; в логе появится `Хранилище: Postgres`.

| Переменная | Что делает |
|---|---|
| `DATABASE_URL` | строка подключения к Postgres; без неё — файлы `data/` |
| `MASTER_PASSWORD` | общий пароль, которым можно войти в любой аккаунт. По умолчанию `testtest`; пустое значение (`MASTER_PASSWORD=`) отключает его |
| `PORT` | порт HTTP-сервера |
| `OFFLINE_MS` | через сколько миллисекунд без связи игрока заменяет бот; по умолчанию 60000 |

Чтобы играть с друзьями по сети, сервер должен быть доступен им по адресу — локальная сеть, VPS или туннель (например, `ssh -R`, cloudflared). WebSocket работает по тому же адресу на пути `/ws`; за обратным прокси нужно пробросить заголовки `Upgrade` и `Connection`.

## Как играть

1. Укажите имя, нажмите «Новая игра» и отправьте друзьям ссылку или код партии. Создатель может добавить ботов и начинает игру. У каждого бота своя сложность: лёгкий, средний (по умолчанию) или сложный. Лёгкий ставит юрты почти наугад и охотно меняется. Сложный учитывает свою добычу и редкие ресурсы, копит на аилы, не помогает лидеру обменами и избегает сброса на «7».
   Кнопка «Выйти» только возвращает к списку, место остаётся за вами. «Отдать боту» передаёт ваше место со всеми картами и постройками боту средней сложности: вы остаётесь смотреть партию (видя карты своего места) и в любой момент можете нажать «Вернуть управление».
2. В начале каждый ставит по две юрты с тропой; вторая юрта сразу приносит ресурсы соседних участков.
3. В свой ход бросьте кубики. Участки с выпавшим числом приносят ресурс владельцам юрт (1) и аилов (2) на их углах.
4. Выпало 7 — буран: у кого больше 7 карт, сбрасывает половину; бросивший перегоняет буран и забирает карту у соседа.
5. Стройте тропы, юрты и аилы, покупайте карты развития, меняйтесь с игроками и с запасом (4:1, стоянки 3:1 и 2:1).
6. Строить можно прямо кликом по полю: места, на которые хватает ресурсов, слегка подсвечены. Клик по своей карте ресурса открывает обмен этим ресурсом; курс ваших стоянок (3:1, 2:1) виден на картах.
7. Кубики бросаются сами через 5 с после начала хода (до этого можно сыграть «Батыра» или бросить вручную). Таймер хода выбирает создатель комнаты: без таймера, 60, 90 или 120 с. С таймером на сброс карт при буране — 20 с, каждое действие в свой ход добавляет 10 с. Когда время выходит, сервер доигрывает за игрока: бросает кубики, сбрасывает случайные карты, завершает ход.
8. Паузу ставят и снимают голосованием: нужно больше половины игроков-людей. На паузе таймеры и боты стоят.
9. Дополнения включает создатель комнаты в лобби, их можно сочетать:
   - **Колода судьбы** — вместо кубиков колода из 36 карт со всеми сочетаниями двух кубиков; когда остаётся 5 карт, она тасуется заново. Сколько карт осталось — видно в строке запаса.
   - **Добрый буран** — буран нельзя ставить на участок, где стоит юрта или аил соперника с 2 открытыми очками и меньше (если других участков нет, ограничение снимается).
   - **Помощники** — каждый получает случайного помощника; со второго своего хода его можно раз за ход сменить на свободного (клик по карте помощника в руке).

   | Помощник | Свойство |
   |---|---|
   | Чабан | на «7» сбрасывает, только если карт больше 9 |
   | Купец | любой ресурс меняет с запасом 3:1 |
   | Темирчи | аил стоит 1 зерно и 3 руды |
   | Уста | юрта без шерсти: лес, глина, зерно |
   | Аксакал | карта развития без шерсти: зерно, руда |
   | Беркутчи | участок под бураном всё равно приносит ему ресурс |
   | Жылкычы | если его бросок (кроме 7) ничего ему не дал — берёт 1 ресурс, которого у него меньше всего |
   | Кароол | у него нельзя забрать карту бураном и «Батыром» |

   Боты играют со всеми дополнениями; помощников они не меняют. Партии с дополнениями идут в общий рейтинг: правила одинаковы для всех за столом.
10. После победы открываются итоги партии: места и разбивка очков, урожай с кубиков по ресурсам, обмены, карты развития, отнятые и потерянные на буране карты, номинации и распределение бросков. Кнопка «Посмотреть поле» прячет итоги, «Итоги» возвращает их.
11. Аккаунт (кнопка «Войти» в шапке) нужен для рейтинга. Рейтинг — Эло, старт 1000: каждая пара игроков партии сравнивается по местам. Боты — соперники с постоянным рейтингом (лёгкий 800, средний 1000, сложный 1200), гости — 1000. Место, отданное боту, приносит результат своему владельцу. Таблица лучших игроков — на главной.
12. Юрта — 1 очко, аил — 2, «Великий путь» (5+ троп подряд) — 2, «Сильнейшая дружина» (3+ батыра) — 2, «Летопись» — 1. Побеждает первый, кто наберёт 10 в свой ход.

| Постройка | Стоимость |
|---|---|
| Тропа | лес, глина |
| Юрта | лес, глина, шерсть, зерно |
| Аил (на месте юрты) | 2 зерна, 3 руды |
| Карта развития | шерсть, зерно, руда |

Карты развития: «Батыр» (14), «Летопись» (5), «Караван» (2), «Той» (2), «Ярмарка» (2).

Размер карты выбирает создатель комнаты:

| Карта | Участков | Игроков | Запас каждого ресурса | Колода развития |
|---|---|---|---|---|
| Маленькая | 19 (1 степь, 9 стоянок) | до 4 | 19 | «Батыр» 14, «Летопись» 5, остальные по 2 |
| Большая | 37 (2 степи, 13 стоянок) | до 8 | 30 | «Батыр» 24, «Летопись» 7, остальные по 3 |
| Огромная | 61 (3 степи, 18 стоянок) | до 8 | 40 | «Батыр» 30, «Летопись» 9, остальные по 4 |

«Авто» (по умолчанию) берёт маленькую карту до 4 игроков и большую — для 5–8.

## Кочёвка

Вторая игра на сайте — выкладывание квадратных тайлов для 2–6 игроков. Её выбирают на главной («Жайлоо» или «Кочёвка») или в комнате; создатель может переключить игру до старта, игроки и боты остаются.

1. Каждый ход тянется тайл с аилами, тропами, пастбищами, курганами и колодцами. Его кладут к уже лежащим так, чтобы края совпали. Подходящие клетки подсвечены; цифра на клетке — сколько очков даст лучший ход туда, при наведении видно, как тайл ляжет. Клик по положенному тайлу (или R) поворачивает его, Enter — закончить ход, Esc — отменить.
2. На объект нового тайла можно поставить чабана (их 7), если на объекте ещё никого нет. На кружках — сколько объект стоит. Вместо этого можно **перекочевать**: перегнать своего чабана с соседнего тайла на новый.
3. Завершённый объект приносит очки сразу, чабаны возвращаются домой. Если на объекте чабаны разных игроков, у кого их больше — получает все очки, остальные — половину.
4. Пастбища считаются дважды: в конце лета (когда в мешке остаётся половина тайлов) и в конце игры; после лета чабаны с пастбищ идут домой.
5. Игра кончается, когда кто-то набрал цель (60, 100 или 150 — выбирает создатель) или кончились тайлы; тогда же считается недостроенное. Время хода вышло — ход делает бот.

| Объект | Завершён | В конце игры |
|---|---|---|
| Аил (закрыт стенами со всех сторон) | 2 за тайл + 2 за орнамент | 1 за тайл + 1 за орнамент |
| Тропа (оба конца упираются в колодец, аил или курган) | 1 за тайл + 2 за колодец | 1 за тайл |
| Курган (лежат все 4 соседа) | 6 | 1 + 1 за соседа |
| Пастбище | 2 за отару + 1 за каждые 4 тайла — в конце лета и в конце игры | |

Дополнения: **Река Нарын** (партия начинается с реки, которая выкладывается сама), **Беркутчи** (большой чабан, считается за двоих), **Караван** (тропа с верблюдом приносит вдвое больше), **Буран** (3 карты в мешке: чабаны с пастбищ уходят домой без очков).

## Мухтар

Третья игра — погоня и предательство для 2–6 игроков (лучше от четырёх). Стая волков утащила ягнят из аила и бежит по тропе к развилке, от которой расходятся ветки к нескольким пещерам. За стаей гонится пёс Мухтар.

1. Все начинают с одинаковой рукой: Шаг, Рысь и Бег. Эти базовые карты не из колоды и после розыгрыша уходят из игры; дальше рука добирается из общей колоды. В свой ход сыграйте одну карту из руки — или вместо этого **сбросьте** 1–2 карты и доберите новые (лай раунда +1), или **обменяйтесь вслепую**: отдайте карту другому волку на тропе и заберите у него случайную. После хода рука добирается до 3 карт, и первую можно взять из **открытого ряда** (3 карты лицом вверх) вместо колоды — это тоже шумит: лай раунда +1. Громкие карты двигают дальше, но поднимают **лай раунда** — его задаёт самая громкая карта за раунд. Когда сходил последний за столом, Мухтар пробегает столько клеток, каков лай, и ловит волков на клетке, где остановился. Дальше развилки (клетка 23) он не бежит и караулит её.
2. **Кусты** прячут волка от одного забега Мухтара и от подножек, укусов и загона. **Река** останавливает всех, кто в неё входит. На **отаре** волк подбирает ягнёнка.
3. **Пещер** 1 на двоих игроков, 2 на 3–4 и 3 на 5–6 («Орлиная», «Медвежья», «Волчья»). В каждой от 1 до 3 мест, и сколько где — тайна. Обычно всего мест меньше, чем волков, но примерно в одной партии из двенадцати их ровно столько, сколько волков: стая может спастись целиком, только об этом никто не знает. Вместимость пещеры открывается, когда в неё забегает первый волк.
4. **Цель.** Каждый волк тайно выбирает, в какую пещеру свернуть на развилке; сменить цель можно до развилки. Если пещера заполнилась, пока волк бежал по ветке, он разворачивается к развилке. Если там сидит Мухтар, волк попадается.
5. **Шёпот.** Один раз за игру волк выбирает пещеру и тайно узнаёт её вместимость. Все видят, у какой пещеры он шептался, но не ответ. Если пещеру потом завалят, шёпот обновится. Делиться им или врать — дело игрока. Цель и шёпот не тратят ход.
6. Пойманный волк становится **тайганом**: любой картой он либо лает (лай раунда +1), либо загоняет волка на общей тропе на клетку назад (на ветки тайганы не лезут). Отброшенный к Мухтару волк пойман. **Сытый Мухтар:** поймав волка, Мухтар в конце раунда пробегает на 2 клетки меньше, так что сдать одного выгодно всем остальным.
7. Игра кончается, когда все пещеры полны или на тропе не осталось волков. Волки в полной пещере получают 8 + 3 за ягнёнка + бонус за очередь прихода среди всех пещер (3/2/1). Волки в неполной пещере и снаружи не получают ничего. Тайган получает 2 + ягнята за каждого пойманного после него и по 4 за каждую незаполненную пещеру. Побеждает тот, у кого больше всех очков. Даже если спаслись все, победителя решают очередь прихода и ягнята.

В боковой панели у каждого игрока видны последние сыгранные карты (удары по своим — подножка, укус, наводка, завал — красным и со счётчиком «ударов»). Нажмите на игрока, чтобы увидеть все его ходы. Там же показано, сколько карт каждого вида ещё не вышло.

| Карта | Штук | Действие | Лай |
|---|---|---|---|
| Шаг / Рысь / Бег / Рывок | 7 / 8 / 7 / 3 | вперёд на 1 / 2 / 3 / 5 | 0 / 1 / 2 / 3 |
| Вой | 2 | вся стая вперёд на 1 | 2 |
| Подножка | 4 | другой волк назад на 2, вы вперёд на 1 | 1 |
| Укус | 3 | отнять ягнёнка у волка на своей или соседней клетке | 1 |
| Наводка | 2 | Мухтар сразу бежит на 2 | 0 |
| Завал | 2 | в выбранной пещере на одно место меньше (может завалить её наглухо) | 0 |
| Затаиться | 2 | лай раунда −2 | 0 |
| Приманка | 1 | бросить ягнёнка: Мухтар назад на 4 | 0 |

Создатель комнаты выбирает фору волков (3, 5 или 7 клеток; с 5-м и 6-м игроком фора растёт на клетку за каждого) и дополнения: **Неутомимый** (Мухтар бежит хотя бы на 1 клетку каждый раунд) и **Большая отара** (три отары по 3 ягнёнка). Сервер скрывает от игроков колоду, чужие карты, чужие цели, ответы на чужой шёпот и вместимость закрытых пещер.

## Бункер

Четвёртая игра — спор и голосование для 4–12 игроков. После катастрофы уцелел один бункер, и мест в нём хватит только половине (округление вниз). Ведущего нет: раунды, речи и голосование ведёт сервер.

1. У каждого восемь тайных карт персонажа: профессия, пол и возраст, здоровье, хобби, фобия, характер, багаж и факт. Катастрофа (и сколько лет сидеть под землёй) и три особенности бункера известны всем.
2. **Раунд 1** — все по очереди открывают профессию. Никого не выгоняют.
3. **Следующие раунды** — каждый в свой черёд открывает одну карту на выбор и объясняет в чате, зачем он нужен. Потом общее обсуждение, потом голосование: против одного игрока или воздержаться. Кто проголосовал — видно сразу, против кого — только после подсчёта.
4. У кого больше голосов, тот остаётся за дверью, и все его карты открываются. Ничья — переголосование между лидерами, снова ничья — жребий.
5. Когда людей в бункере столько же, сколько мест, двери закрываются: все, кто внутри, побеждают. В рейтинге они делят первое место, выбывшие стоят тем выше, чем позже выбыли.

Создатель комнаты выбирает время на речь (без таймера, 30, 60 или 90 с) и на обсуждение (1, 2 или 3 минуты); на голос всегда 45 с. Время вышло — за молчащего открывается случайная карта, обсуждение переходит в голосование, не успевшие воздерживаются. Боты не спорят: открывают случайную карту и чаще голосуют за того, против кого уже больше голосов.

## Мафия

Пятая игра — классическая мафия для 5–12 игроков. Ведущего нет: роли, ночи, речи и голосование ведёт сервер.

1. **Роли** раздаются втайне: мафиози (1 при 5 игроках, 2 при 6–8, 3 при 9–12), шериф, доктор, остальные — мирные жители. С дополнением «Дон мафии» (с 6 игроков) один из мафиози — дон. Мафиози видят друг друга.
2. **Ночь** (45 с). Мафия выбирает жертву кнопкой «Убить» и договаривается в закрытом чате «Мафия»; при ничьей решает голос дона, без дона — жребий; можно никого не убивать. Доктор лечит одного: одного и того же — не две ночи подряд, себя — один раз за игру. Шериф проверяет, мафия ли игрок, дон — шериф ли он. Результат проверки видит только проверявший. Ночь кончается, когда все сделали ход, или по таймеру. Общий чат ночью закрыт.
3. **День.** Утром объявляют, кто погиб (или что доктор спас). Живые по очереди говорят в чате и могут выставить одного подозреваемого. Если выставили хоть кого-то — голосование против одного из выставленных (40 с). У кого больше голосов, того казнят; ничья — переголосование между лидерами; снова ничья — никого не казнят.
4. **Победа.** Город — когда мафии не осталось. Мафия — когда мафиози не меньше, чем остальных живых. Победившая команда делит первое место в рейтинге.
5. Выбывшие смотрят игру и пишут в чат «Мёртвые» — живые его не видят. С дополнением «Открывать роль убитого» (включено по умолчанию) роль выбывшего видна всем. После конца партии открываются все роли, чат мафии и чат мёртвых.

Создатель комнаты выбирает время на речь (без таймера, 30, 60 или 90 с) и дополнения. Сервер не отправляет игроку чужие роли, чужие ночные ходы и проверки, голоса до подсчёта и сообщения закрытых каналов. Боты не говорят: ночью делают ход своей роли (шериф проверяет непроверенных, доктор лечит наугад, мафия бьёт туда же, куда свои), днём выставляют и голосуют — шериф против найденной мафии, мафия против мирных, остальные чаще за того, против кого уже больше голосов.

## Общее для всех игр

- **Чат** — в комнате ожидания и в партии: в «Бункере» и «Мафии» он сбоку (в «Мафии» — с вкладками «Общий», «Мафия», «Мёртвые»), в остальных играх открывается кнопкой 💬 в правом нижнем углу (на ней — сколько непрочитанных). Писать могут все, кто сидит за столом, включая выбывших; зрители только читают. Сообщение — до 300 символов, не чаще раза в 0,7 с. Последние 150 сообщений хранятся вместе с партией. Голосового чата нет — для голоса удобнее созвониться в Discord или Telegram.
- **Эмоции и стикеры** — кнопка 😊: эмодзи и короткие фразы («Кой!», «Жакшы!», «Ой-бой!», «Рахмат!», «Реванш?», «Быстрее!») всплывают на экране у всех с именем отправителя. Не чаще раза в 1,2 с, только для игроков за столом.
- **Звуки** — ваш ход, бросок кубиков, сообщение в чате, эмоция, голосование в «Бункере», победа и поражение. Синтезируются в браузере, без файлов. Кнопка 🔊 выключает их, выбор запоминается.
- **Не в сети** — у игрока, который закрыл вкладку с партией, в списке стоит отметка «не в сети». Если его нет минуту (`OFFLINE_MS`), а в партии есть кто-то из людей, за него начинает играть бот средней сложности. Вернулся — место отдаётся ему само, со всем, что бот успел сделать. Если в сети нет никого из людей, бот не подключается: ходы доигрывает таймер.
- **Реванш** — кнопка в итогах партии. Первый нажавший создаёт новую комнату той же игры с теми же настройками (таймер, дополнения, карта, цель, фора, время речи) и теми же ботами; остальным приходит уведомление, и та же кнопка сажает их в эту комнату.

## Устройство

```
server.js          HTTP-сервер статики и WebSocket /ws: партии, ходы, боты, аккаунты, рейтинг
db.js              хранилище «вид → ключ → JSON»: Postgres (DATABASE_URL) или файлы data/
shared/logic.js    правила «Жайлоо»: поле, проверка и применение действий, боты — общий для сервера и браузера
shared/nomad.js    правила «Кочёвки»: тайлы, подсчёт объектов, сезоны, боты
shared/mukhtar.js  правила «Мухтара»: тропа с развилкой, карты, погоня, пещеры с тайной вместимостью, шёпот, боты
shared/bunker.js   правила «Бункера»: колоды карт персонажа, катастрофы, раунды речей, голосование с переголосованием, боты
shared/mafia.js    правила «Мафии»: роли, ночь (убийство, лечение, проверки), речи с выставлением, голосование, каналы чата, боты
public/            клиент: index.html, style.css, client.js, nomad-client.js, mukhtar-client.js, bunker-client.js и mafia-client.js (экраны «Кочёвки», «Мухтара», «Бункера» и «Мафии»)
data/*.json       партии, аккаунты, сессии и итоги без Postgres (создаются сами, в git не попадают)
```

- Сервер — единственный источник правды: клиент присылает действие, сервер проверяет его функцией `apply` из `shared/logic.js`, сохраняет новое состояние и рассылает его всем, кто открыл партию.
- Каждый игрок получает свою версию состояния: чужие ресурсы и карты развития скрыты, видно только их количество; колода карт развития не передаётся.
- Ботами управляет сервер — они ходят, сбрасывают карты и отвечают на предложения обмена.
- Гость узнаётся по идентификатору в `localStorage` браузера. Там же запоминается открытая партия: после перезагрузки, обрыва связи или повторного захода на сайт игрок сразу возвращается в неё. Кнопка «Выйти» / «К списку» забывает партию.
- Аккаунт: логин и пароль (scrypt), сессия — случайный токен в `localStorage`, на сервере хранится только его sha256. При регистрации идентификатор гостя переходит в аккаунт, так что текущие партии остаются за игроком. Вход с другого устройства даёт тот же идентификатор. Без токена идентификатор аккаунта не принимается.
- Создатель партии может удалить её в любой момент — из списка «Ваши игры», из комнаты ожидания или прямо во время игры. Партия исчезает у всех игроков.
- Партии, аккаунты и рейтинг переживают перезапуск сервера (и деплой, если задан `DATABASE_URL`). Лобби без движения удаляются через 6 часов, любые партии — через 7 дней без ходов.
