# Жайлоо

Онлайн-настольная игра для 2–8 игроков в браузере: юрты и аилы на горных пастбищах, тропы, торговля, карты развития и буран. Свободные места можно отдать ботам.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Откройте http://localhost:3000. Во время разработки удобнее `npm run dev`: сервер сам перезапускается, когда меняются `server.js` или `shared/logic.js`. Порт меняется переменной `PORT`:

```bash
PORT=8080 npm start
```

Чтобы играть с друзьями по сети, сервер должен быть доступен им по адресу — локальная сеть, VPS или туннель (например, `ssh -R`, cloudflared). WebSocket работает по тому же адресу на пути `/ws`; за обратным прокси нужно пробросить заголовки `Upgrade` и `Connection`.

## Как играть

1. Укажите имя, нажмите «Новая игра» и отправьте друзьям ссылку или код партии. Создатель может добавить ботов и начинает игру. У каждого бота своя сложность: лёгкий, средний (по умолчанию) или сложный. Лёгкий ставит юрты почти наугад и охотно меняется. Сложный учитывает свою добычу и редкие ресурсы, копит на аилы, не помогает лидеру обменами и избегает сброса на «7».
   Кнопка «Выйти» только возвращает к списку, место остаётся за вами. «Отдать боту» передаёт ваше место со всеми картами и постройками боту средней сложности: вы остаётесь смотреть партию (видя карты своего места) и в любой момент можете нажать «Вернуть управление».
2. В начале каждый ставит по две юрты с тропой; вторая юрта сразу приносит ресурсы соседних участков.
3. В свой ход бросьте кубики. Участки с выпавшим числом приносят ресурс владельцам юрт (1) и аилов (2) на их углах.
4. Выпало 7 — буран: у кого больше 7 карт, сбрасывает половину; бросивший перегоняет буран и забирает карту у соседа.
5. Стройте тропы, юрты и аилы, покупайте карты развития, меняйтесь с игроками и с запасом (4:1, стоянки 3:1 и 2:1).
6. Строить можно прямо кликом по полю: места, на которые хватает ресурсов, слегка подсвечены. Клик по своей карте ресурса открывает обмен этим ресурсом; курс ваших стоянок (3:1, 2:1) виден на картах.
7. Кубики бросаются сами через 5 с после начала хода (до этого можно сыграть «Батыра» или бросить вручную). Таймер хода выбирает создатель комнаты: без таймера, 60, 90 или 120 с. С таймером на сброс карт при буране — 20 с, каждое действие в свой ход добавляет 10 с. Когда время выходит, сервер доигрывает за игрока: бросает кубики, сбрасывает случайные карты, завершает ход.
8. Паузу ставят и снимают голосованием: нужно больше половины игроков-людей. На паузе таймеры и боты стоят.
9. Юрта — 1 очко, аил — 2, «Великий путь» (5+ троп подряд) — 2, «Сильнейшая дружина» (3+ батыра) — 2, «Летопись» — 1. Побеждает первый, кто наберёт 10 в свой ход.

| Постройка | Стоимость |
|---|---|
| Тропа | лес, глина |
| Юрта | лес, глина, шерсть, зерно |
| Аил (на месте юрты) | 2 зерна, 3 руды |
| Карта развития | шерсть, зерно, руда |

Карты развития: «Батыр» (14), «Летопись» (5), «Караван» (2), «Той» (2), «Ярмарка» (2).

Размер карты выбирает создатель комнаты:

| Карта | Участков | Игроков | Запас каждого ресурса | Колода развития |
|---|---|---|---|---|
| Маленькая | 19 (1 степь, 9 стоянок) | до 4 | 19 | «Батыр» 14, «Летопись» 5, остальные по 2 |
| Большая | 37 (2 степи, 13 стоянок) | до 8 | 30 | «Батыр» 24, «Летопись» 7, остальные по 3 |
| Огромная | 61 (3 степи, 18 стоянок) | до 8 | 40 | «Батыр» 30, «Летопись» 9, остальные по 4 |

«Авто» (по умолчанию) берёт маленькую карту до 4 игроков и большую — для 5–8.

## Устройство

```
server.js          HTTP-сервер статики и WebSocket /ws: партии, ходы, боты, сохранение
shared/logic.js    правила игры: поле, проверка и применение действий, боты — общий для сервера и браузера
public/            клиент: index.html, style.css, client.js
data/games.json    сохранённые партии (создаётся сам, в git не попадает)
```

- Сервер — единственный источник правды: клиент присылает действие, сервер проверяет его функцией `apply` из `shared/logic.js`, сохраняет новое состояние и рассылает его всем, кто открыл партию.
- Каждый игрок получает свою версию состояния: чужие ресурсы и карты развития скрыты, видно только их количество; колода карт развития не передаётся.
- Ботами управляет сервер — они ходят, сбрасывают карты и отвечают на предложения обмена.
- Игрок узнаётся по идентификатору в `localStorage` браузера. Там же запоминается открытая партия: после перезагрузки, обрыва связи или повторного захода на сайт игрок сразу возвращается в неё. Кнопка «Выйти» / «К списку» забывает партию. Аккаунтов и паролей нет.
- Создатель партии может удалить её в любой момент — из списка «Ваши игры», из комнаты ожидания или прямо во время игры. Партия исчезает у всех игроков.
- Партии сохраняются в `data/games.json` и переживают перезапуск сервера. Лобби без движения удаляются через 6 часов, любые партии — через 7 дней без ходов.
