# Жайлоо

Онлайн-настольная игра для 2–8 игроков в браузере: юрты и аилы на горных пастбищах, тропы, торговля, карты развития и буран. Свободные места можно отдать ботам.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Откройте http://localhost:3000. Во время разработки удобнее `npm run dev`: сервер сам перезапускается, когда меняются `server.js` или `shared/logic.js`. Порт меняется переменной `PORT`:

```bash
PORT=8080 npm start
```

## Хранилище и деплой на Render

Без переменной `DATABASE_URL` партии, аккаунты и рейтинг лежат в файлах `data/*.json` — этого хватает для локального запуска. На Render файловая система стирается при каждом деплое и перезапуске, поэтому там нужна база Postgres:

1. Создайте базу: бесплатную в [Neon](https://neon.tech) или Supabase, либо Postgres в самом Render.
2. В настройках веб-сервиса Render → Environment добавьте `DATABASE_URL` — строку подключения (у Neon она уже с `?sslmode=require`; у Postgres из Render берите Internal Database URL).
3. Задеплойте. Таблица `kv` создастся сама; в логе появится `Хранилище: Postgres`.

| Переменная | Что делает |
|---|---|
| `DATABASE_URL` | строка подключения к Postgres; без неё — файлы `data/` |
| `MASTER_PASSWORD` | общий пароль, которым можно войти в любой аккаунт. По умолчанию `testtest`; пустое значение (`MASTER_PASSWORD=`) отключает его |
| `PORT` | порт HTTP-сервера |

Чтобы играть с друзьями по сети, сервер должен быть доступен им по адресу — локальная сеть, VPS или туннель (например, `ssh -R`, cloudflared). WebSocket работает по тому же адресу на пути `/ws`; за обратным прокси нужно пробросить заголовки `Upgrade` и `Connection`.

## Как играть

1. Укажите имя, нажмите «Новая игра» и отправьте друзьям ссылку или код партии. Создатель может добавить ботов и начинает игру. У каждого бота своя сложность: лёгкий, средний (по умолчанию) или сложный. Лёгкий ставит юрты почти наугад и охотно меняется. Сложный учитывает свою добычу и редкие ресурсы, копит на аилы, не помогает лидеру обменами и избегает сброса на «7».
   Кнопка «Выйти» только возвращает к списку, место остаётся за вами. «Отдать боту» передаёт ваше место со всеми картами и постройками боту средней сложности: вы остаётесь смотреть партию (видя карты своего места) и в любой момент можете нажать «Вернуть управление».
2. В начале каждый ставит по две юрты с тропой; вторая юрта сразу приносит ресурсы соседних участков.
3. В свой ход бросьте кубики. Участки с выпавшим числом приносят ресурс владельцам юрт (1) и аилов (2) на их углах.
4. Выпало 7 — буран: у кого больше 7 карт, сбрасывает половину; бросивший перегоняет буран и забирает карту у соседа.
5. Стройте тропы, юрты и аилы, покупайте карты развития, меняйтесь с игроками и с запасом (4:1, стоянки 3:1 и 2:1).
6. Строить можно прямо кликом по полю: места, на которые хватает ресурсов, слегка подсвечены. Клик по своей карте ресурса открывает обмен этим ресурсом; курс ваших стоянок (3:1, 2:1) виден на картах.
7. Кубики бросаются сами через 5 с после начала хода (до этого можно сыграть «Батыра» или бросить вручную). Таймер хода выбирает создатель комнаты: без таймера, 60, 90 или 120 с. С таймером на сброс карт при буране — 20 с, каждое действие в свой ход добавляет 10 с. Когда время выходит, сервер доигрывает за игрока: бросает кубики, сбрасывает случайные карты, завершает ход.
8. Паузу ставят и снимают голосованием: нужно больше половины игроков-людей. На паузе таймеры и боты стоят.
9. Дополнения включает создатель комнаты в лобби, их можно сочетать:
   - **Колода судьбы** — вместо кубиков колода из 36 карт со всеми сочетаниями двух кубиков; когда остаётся 5 карт, она тасуется заново. Сколько карт осталось — видно в строке запаса.
   - **Добрый буран** — буран нельзя ставить на участок, где стоит юрта или аил соперника с 2 открытыми очками и меньше (если других участков нет, ограничение снимается).
   - **Помощники** — каждый получает случайного помощника; со второго своего хода его можно раз за ход сменить на свободного (клик по карте помощника в руке).

   | Помощник | Свойство |
   |---|---|
   | Чабан | на «7» сбрасывает, только если карт больше 9 |
   | Купец | любой ресурс меняет с запасом 3:1 |
   | Темирчи | аил стоит 1 зерно и 3 руды |
   | Уста | юрта без шерсти: лес, глина, зерно |
   | Аксакал | карта развития без шерсти: зерно, руда |
   | Беркутчи | участок под бураном всё равно приносит ему ресурс |
   | Жылкычы | если его бросок (кроме 7) ничего ему не дал — берёт 1 ресурс, которого у него меньше всего |
   | Кароол | у него нельзя забрать карту бураном и «Батыром» |

   Боты играют со всеми дополнениями; помощников они не меняют. Партии с дополнениями идут в общий рейтинг: правила одинаковы для всех за столом.
10. После победы открываются итоги партии: места и разбивка очков, урожай с кубиков по ресурсам, обмены, карты развития, отнятые и потерянные на буране карты, номинации и распределение бросков. Кнопка «Посмотреть поле» прячет итоги, «Итоги» возвращает их.
11. Аккаунт (кнопка «Войти» в шапке) нужен для рейтинга. Рейтинг — Эло, старт 1000: каждая пара игроков партии сравнивается по местам. Боты — соперники с постоянным рейтингом (лёгкий 800, средний 1000, сложный 1200), гости — 1000. Место, отданное боту, приносит результат своему владельцу. Таблица лучших игроков — на главной.
12. Юрта — 1 очко, аил — 2, «Великий путь» (5+ троп подряд) — 2, «Сильнейшая дружина» (3+ батыра) — 2, «Летопись» — 1. Побеждает первый, кто наберёт 10 в свой ход.

| Постройка | Стоимость |
|---|---|
| Тропа | лес, глина |
| Юрта | лес, глина, шерсть, зерно |
| Аил (на месте юрты) | 2 зерна, 3 руды |
| Карта развития | шерсть, зерно, руда |

Карты развития: «Батыр» (14), «Летопись» (5), «Караван» (2), «Той» (2), «Ярмарка» (2).

Размер карты выбирает создатель комнаты:

| Карта | Участков | Игроков | Запас каждого ресурса | Колода развития |
|---|---|---|---|---|
| Маленькая | 19 (1 степь, 9 стоянок) | до 4 | 19 | «Батыр» 14, «Летопись» 5, остальные по 2 |
| Большая | 37 (2 степи, 13 стоянок) | до 8 | 30 | «Батыр» 24, «Летопись» 7, остальные по 3 |
| Огромная | 61 (3 степи, 18 стоянок) | до 8 | 40 | «Батыр» 30, «Летопись» 9, остальные по 4 |

«Авто» (по умолчанию) берёт маленькую карту до 4 игроков и большую — для 5–8.

## Устройство

```
server.js          HTTP-сервер статики и WebSocket /ws: партии, ходы, боты, аккаунты, рейтинг
db.js              хранилище «вид → ключ → JSON»: Postgres (DATABASE_URL) или файлы data/
shared/logic.js    правила игры: поле, проверка и применение действий, боты — общий для сервера и браузера
public/            клиент: index.html, style.css, client.js
data/*.json       партии, аккаунты, сессии и итоги без Postgres (создаются сами, в git не попадают)
```

- Сервер — единственный источник правды: клиент присылает действие, сервер проверяет его функцией `apply` из `shared/logic.js`, сохраняет новое состояние и рассылает его всем, кто открыл партию.
- Каждый игрок получает свою версию состояния: чужие ресурсы и карты развития скрыты, видно только их количество; колода карт развития не передаётся.
- Ботами управляет сервер — они ходят, сбрасывают карты и отвечают на предложения обмена.
- Гость узнаётся по идентификатору в `localStorage` браузера. Там же запоминается открытая партия: после перезагрузки, обрыва связи или повторного захода на сайт игрок сразу возвращается в неё. Кнопка «Выйти» / «К списку» забывает партию.
- Аккаунт: логин и пароль (scrypt), сессия — случайный токен в `localStorage`, на сервере хранится только его sha256. При регистрации идентификатор гостя переходит в аккаунт, так что текущие партии остаются за игроком. Вход с другого устройства даёт тот же идентификатор. Без токена идентификатор аккаунта не принимается.
- Создатель партии может удалить её в любой момент — из списка «Ваши игры», из комнаты ожидания или прямо во время игры. Партия исчезает у всех игроков.
- Партии, аккаунты и рейтинг переживают перезапуск сервера (и деплой, если задан `DATABASE_URL`). Лобби без движения удаляются через 6 часов, любые партии — через 7 дней без ходов.
